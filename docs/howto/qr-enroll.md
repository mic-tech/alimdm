# Enrolling with a QR Code — superseded

This guide has been replaced by **[`zero-touch-qr.md`](zero-touch-qr.md)**.

It described a hybrid where the QR set Device Owner and ADB installed the app,
because carrying the install in the QR was still uncertain when it was written.
It is not uncertain any more: the QR names a download URL on your own server,
the setup wizard fetches and verifies the staged build, and no cable is
involved at any point. Following the old advice would have you plug in a USB
cable for no reason.

See [`zero-touch-qr.md`](zero-touch-qr.md).
